# ปวดเฮด (PuadHead) — คู่มือการใช้งาน

แอปบันทึกอาการปวดหัว ใช้งานได้ทันทีไม่ต้องสมัครสมาชิก เก็บข้อมูลไว้ในเครื่องของคุณเอง

## เรื่องเบื้องหลัง

แอปนี้เริ่มจากแฟนของผมปวดหัวบ่อยจนต้องไปโรงพยาบาล หมอวินิจฉัยว่าเป็นไมเกรน ทำ MRI นอนโรงพยาบาลรักษาต่อเนื่อง ต้องกินยาปรับสมดุลสารเคมีในสมองทุกวัน บวกกับยาที่ออกฤทธิ์เร็ว (อมใต้ลิ้น) สำหรับตอนปวดหนัก ที่ราคาสูงมาก — เม็ดละเป็นพันบาท

ระหว่างดูแลกันไปมา ผมสังเกตว่าไม่มีเครื่องมือไหนที่ช่วยบันทึกอาการปวดหัวได้ง่ายพอสำหรับตอนที่กำลังปวดจริงๆ สมุดจดก็หาไม่เจอ พิมพ์โน้ตในมือถือก็ไม่มีโครงสร้าง พอถึงเวลาไปหาหมอก็นึกไม่ออกว่าเดือนที่ผ่านมาปวดกี่ครั้ง กินยาไปกี่เม็ด อาการแต่ละครั้งเป็นแบบไหนบ้าง

**ปวดเฮดเลยเกิดขึ้นจากโจทย์เดียว: ตอนหัวกำลังปวดอยู่ ต้องบันทึกได้ไวและง่ายที่สุด** ไม่ว่าจะเป็นคนที่วินิจฉัยแล้วอย่างแฟนผม หรือคนที่ยังไม่รู้ว่าตัวเองเป็นอะไร อยากมีข้อมูลสะสมไว้ให้หมอดูตอนไปพบจริง

## แอปนี้เหมาะกับใคร

- คนที่ปวดหัวบ่อย ไม่ว่าจะรู้การวินิจฉัยแล้วหรือยังไม่รู้
- อยากมีข้อมูลที่เป็นระบบพกไปให้หมอดูตอนนัดตรวจ แทนการนึกย้อนหลังเอาเอง
- อยากติดตามว่าใช้ยาแก้ปวดถี่แค่ไหน (เกี่ยวข้องกับความเสี่ยง "ปวดหัวจากการใช้ยาเกิน" หากใช้ยาแก้ปวดบ่อยเกินไป)

**สิ่งที่แอปนี้ไม่ใช่**: ไม่ใช่เครื่องมือวินิจฉัยโรค ไม่ให้คำแนะนำทางการแพทย์ และไม่ตีความข้อมูลใดๆ ที่บันทึกไว้ — ทำหน้าที่เก็บข้อมูลให้ครบและเป็นระบบเท่านั้น การวินิจฉัยและการรักษาทั้งหมดยังต้องผ่านแพทย์เสมอ

## เริ่มต้นใช้งาน

1. เปิดลิงก์แอป แล้วกด **"บันทึกวันนี้"** ได้เลย ไม่ต้องสมัครสมาชิกหรือ login ก่อน
2. อยากใช้แบบ app จริง (ไม่ใช่แค่หน้าเว็บ) กด "เพิ่มลงหน้าจอโฮม" จากเมนูเบราว์เซอร์ได้ทั้ง iPhone/Android — ใช้งานได้แม้ไม่มีเน็ต

## ฟีเจอร์หลัก

### บันทึกอาการ (หน้า "วันนี้")

กดปุ่ม "บันทึกวันนี้" หรือแตะวันที่ต้องการในปฏิทิน (บันทึกย้อนหลังได้) กรอกทีละส่วน:

- **ระดับความปวด** — 3 ระดับ (เล็กน้อย / ปานกลาง / รุนแรง) พร้อมคำอธิบายผลกระทบต่อการทำกิจกรรม
- **เวลาเริ่มปวด–เวลาหาย**
- **อาการร่วม** — เลือกได้จาก 15 อาการ (ไวต่อแสง, ไวต่อเสียง, ไวต่อกลิ่น, คลื่นไส้, ออร่า, เวียนหัวบ้านหมุน, มองเห็นไม่ชัด, ชา/อ่อนแรงครึ่งซีก, หูอื้อ, ทรงตัวไม่ได้, สับสน, ไข้, อ่อนเพลีย, คอ/บ่าตึงแข็ง, นอนหลับผิดปกติ) — โชว์ 4 อาการหลักก่อน กด "ดูอาการเพิ่มเติม" เพื่อดูทั้งหมด
- **ตำแหน่งที่ปวด** — ขมับ / ท้ายทอย / กระหม่อม / หน้าผาก / เบ้าตา / ทั้งหัว เลือกได้หลายตำแหน่ง
- **ยาที่ใช้** — เลือกจากรายการยาที่เคยเพิ่มไว้ (ดูหัวข้อ "จัดการยา" ด้านล่าง)
- **บริบทเพิ่มเติม** — วันฉีดยา CGRP, มีประจำเดือน
- **โน้ตเพิ่มเติม** — พิมพ์อะไรก็ได้ที่ไม่มีช่องให้กรอก

หน้า "วันนี้" ยังมี **ปฏิทินสรุปทั้งเดือน** (สีเข้มขึ้นตามความรุนแรง) กับตัวเลขสรุป "วันที่ปวด" / "วันที่ทานยา" ให้เห็นภาพรวมทันทีที่เปิดแอป

### จัดการยา

กดปุ่ม "จัดการยา" จากหน้าบันทึก เพิ่มยาที่ใช้ประจำไว้ล่วงหน้า (ชื่อยา, ประเภท acute/preventive, ถ่ายรูปซองยาได้) ครั้งเดียวแล้วเลือกใช้ซ้ำได้ทุกครั้งที่บันทึก

### บันทึกผลวินิจฉัย

หลังไปพบแพทย์แล้วรู้ผลวินิจฉัย กดที่ป้ายด้านบนหน้า "วันนี้" เพื่อบันทึก: วันที่วินิจฉัย, หมอบอกว่าเป็นอะไร, ยาที่หมอสั่ง (เลือกจากรายการยาเดียวกับที่ใช้บันทึกประจำ), โน้ตเพิ่มเติม — เก็บแยกจากบันทึกอาการรายวัน ไว้เทียบดูภาพรวมได้

### รายงาน

- เลือกช่วงเวลาดู (1/3/6 เดือน หรือกำหนดเอง)
- ดูเป็น **"รายการ"** (แต่ละครั้งที่บันทึกพร้อมรายละเอียด) หรือ **"ตาราง (ให้หมอดู)"** (ตารางรายวันเต็มเดือน เหมาะเปิดโชว์หมอสดๆ)
- **ส่งออก PDF** พกไปให้หมอดูหรือเก็บไว้เป็นหลักฐาน

### ระวังการใช้ยาเกิน

ถ้าใช้ยาแก้ปวดถี่เกินเกณฑ์ (10 วัน/เดือนสำหรับยาบางกลุ่ม — เป็นเกณฑ์ทั่วไปที่ใช้อ้างอิง ไม่ใช่ข้อสรุปทางการแพทย์ตายตัว) แอปจะขึ้นแบนเนอร์เตือนที่หน้า "วันนี้" ให้สังเกต ไม่ใช่คำวินิจฉัยหรือคำสั่งให้หยุดยา — ควรปรึกษาแพทย์/เภสัชกรเสมอ

### ซิงค์ข้ามเครื่อง (ทางเลือก ไม่บังคับ)

ปุ่ม "ซิงค์ข้ามเครื่อง" มุมบนขวา — กดเพื่อ login ด้วย Google หรืออีเมล/รหัสผ่าน ถ้าอยากใช้แอปได้จากหลายเครื่อง (เช่น มือถือ + แท็บเล็ต) ข้อมูลเดิมที่เคยบันทึกไว้จะย้ายขึ้นระบบให้อัตโนมัติตอน login ครั้งแรก

**ไม่ login ก็ใช้แอปได้ครบทุกฟีเจอร์** — เป็นแค่ตัวเลือกเสริมสำหรับคนที่อยากสำรองข้อมูล/ใช้หลายเครื่อง

## เรื่องข้อมูลและความเป็นส่วนตัว

- **ไม่ login**: ข้อมูลทั้งหมดเก็บอยู่ในเครื่องนี้เครื่องเดียว ไม่ถูกส่งออกไปที่ไหนเลย
- **Login แล้ว**: ข้อมูลซิงค์ขึ้นระบบคลาวด์ (Firebase) เพื่อดูได้จากหลายเครื่อง เข้าถึงได้เฉพาะบัญชีของคุณเท่านั้น
- ไม่มีการแชร์ข้อมูลให้บุคคลที่สาม ไม่มีการวิเคราะห์ข้อมูลเพื่อโฆษณาหรือวัตถุประสงค์อื่นใด

## คำถามที่พบบ่อย

**บันทึกย้อนหลังได้ไหม?** ได้ — แตะวันที่ต้องการในปฏิทินได้เลย (วันในอนาคตบันทึกล่วงหน้าไม่ได้)

**ลืม login แล้วบันทึกไปหลายวัน ข้อมูลจะหายไหมถ้า login ทีหลัง?** ไม่หาย — ข้อมูลเดิมที่บันทึกไว้ตอนไม่ login จะถูกย้ายเข้าระบบให้อัตโนมัติตอน login ครั้งแรก

**ใช้ตอนไม่มีเน็ตได้ไหม?** ได้ ถ้าเพิ่มแอปลงหน้าจอโฮมแล้ว (ทำงานแบบ PWA รองรับ offline)

**ปวดหัวชนิดอื่นที่ไม่ใช่ไมเกรนใช้ได้ไหม?** ได้ — ช่องอาการและตำแหน่งที่ปวดออกแบบให้ครอบคลุมอาการปวดหัวทั่วไป ไม่ได้ผูกกับไมเกรนอย่างเดียว
