# ปวดเฮด (PuadHead)

แอปบันทึกอาการปวดหัว ใช้งานได้ทันทีไม่ต้องสมัครสมาชิก ข้อมูลเก็บในเครื่องคุณเอง เลือกซิงค์ข้ามเครื่องได้ภายหลังถ้าต้องการ

🔗 **ใช้งานได้ที่**: https://puadheadd.web.app

## เรื่องเบื้องหลัง

แอปนี้เริ่มจากแฟนของผมปวดหัวบ่อยจนต้องไปโรงพยาบาล หมอวินิจฉัยว่าเป็นไมเกรน ทำ MRI นอนโรงพยาบาลรักษาต่อเนื่อง ต้องกินยาปรับสมดุลสารเคมีในสมองทุกวัน บวกกับยาที่ออกฤทธิ์เร็ว (อมใต้ลิ้น) สำหรับตอนปวดหนัก ที่ราคาสูงมาก — เม็ดละเป็นพันบาท

ระหว่างดูแลกันไปมา ผมสังเกตว่าไม่มีเครื่องมือไหนที่ช่วยบันทึกอาการปวดหัวได้ง่ายพอสำหรับตอนที่กำลังปวดจริงๆ พอถึงเวลาไปหาหมอก็นึกไม่ออกว่าเดือนที่ผ่านมาปวดกี่ครั้ง กินยาไปกี่เม็ด อาการแต่ละครั้งเป็นแบบไหนบ้าง

ปวดเฮดเลยเกิดขึ้นจากโจทย์เดียว: **ตอนหัวกำลังปวดอยู่ ต้องบันทึกได้ไวและง่ายที่สุด** ไม่ว่าจะเป็นคนที่วินิจฉัยแล้ว หรือคนที่ยังไม่รู้ว่าตัวเองเป็นอะไร อยากมีข้อมูลสะสมไว้ให้หมอดูตอนไปพบจริง

**แอปนี้ไม่ใช่เครื่องมือวินิจฉัยโรคหรือให้คำแนะนำทางการแพทย์** — ทำหน้าที่เก็บข้อมูลให้ครบและเป็นระบบเท่านั้น การวินิจฉัยและการรักษาทั้งหมดยังต้องผ่านแพทย์เสมอ

## ฟีเจอร์

- บันทึกด่วน: ระดับความปวด, เวลาเริ่ม–หาย, อาการร่วม (15 ตัวเลือก), ตำแหน่งที่ปวด, ยาที่ใช้
- บันทึกย้อนหลังได้ผ่านปฏิทินสรุปทั้งเดือน
- จัดการรายการยาที่ใช้ประจำ (พร้อมถ่ายรูปซองยา)
- บันทึกผลวินิจฉัยจากแพทย์แยกต่างหาก
- รายงานแบบรายการ/ตาราง + ส่งออก PDF ให้หมอดู
- แจ้งเตือนการใช้ยาแก้ปวดถี่เกินเกณฑ์
- ใช้ได้แบบ PWA ติดตั้งลงหน้าจอโฮม ทำงาน offline ได้
- ซิงค์ข้ามเครื่องแบบเลือกได้ (Google หรืออีเมล/รหัสผ่าน) — ไม่ login ก็ใช้ได้ครบทุกฟีเจอร์

**คู่มือการใช้งานฉบับเต็ม**: [`docs/user-guide.md`](docs/user-guide.md)

## Tech stack

- React + Vite, Tailwind v4, `vite-plugin-pwa`, `react-router-dom`, `zustand`
- Firebase Auth + Firestore (ใช้เฉพาะตอนเลือกซิงค์), IndexedDB (`idb`) เป็น source of truth ตอนไม่ login
- `@react-pdf/renderer` สำหรับ export PDF

## Development

```bash
npm install
npm run dev      # dev server
npm run build    # production build
npm run lint     # oxlint
npm run deploy   # build + deploy Firebase Hosting
npm run deploy:rules   # deploy Firestore security rules
```

ต้องตั้งค่า Firebase project ของตัวเองใน `.env` (ดู `.env.example`) ก่อนรัน
